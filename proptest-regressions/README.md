# Property-test regressions

Proptest uses its default source-parallel failure persistence, so a minimized failing seed is written below this directory in a path matching the Rust source file (for example, `net/transition.txt`).

When a property test finds a defect:

1. Keep the minimized `cc <seed>` entry generated by Proptest.
2. Add a focused named regression test when the seed alone does not explain the behavior.
3. Commit the generated seed and the fix together; do not delete historical seeds merely because a generator changes.

The initial T5.1 property runs completed without finding a defect, so there are no seed files yet.
